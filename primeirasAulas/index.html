é possível pular linhas de texto usando o br.
Além disso podemos deixar alguns caracteres em bold usando a tag strongou em itálico usando o em.

Para criar listas não ordenadas usamos o ul

  • cada elemento é invocado usando um li dentro da lista;
  • Cada um é representado por um ponto na frente;
  • Mas todos esses elementos podem ser auterados usando uma linguagem de estilização como o CSS.

Já para criar as listas ordenadas usamos o ol:

  1. Assim como o ul, utiliza-se o li para cada elemento;
  2. Cada um é representado por um número na ordem crescente;
  3. Ainda assim é possível reverter para a ordem decrescente colocando o reversed a frente do ol.

Para usarmos links podemos usar a tag a, colocando o caminho dentro do href. Podendo ainda usar a tag target="_blank" dentro do "a" para fazer com que se abra em uma nova aba.

Para colocar imagens usamos o comando img e colocamos o caminho pelo src que fica dentro do img. Ele aceita tanto caminhos dentro do computador quanto caminhos web.
